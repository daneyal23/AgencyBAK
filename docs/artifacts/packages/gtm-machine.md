# GTM Machine

## Tagline

The machine behind the pipeline — built so you can run it.

## For whom

Traditional SMEs and B2B service firms (and food operators with serious corporate TAM) ready for signal-based lists, durable workflows, and RevOps that survives the agency leaving.

## What’s in

| Capability | Role in the package |
|------------|---------------------|
| GTM strategy | Bet selection and ignore list (lighter if already clear from a prior Starter) |
| GTM engineering | Account universe, enrichment, send paths, orchestration in tools you own |
| Outbound & lead gen | Production sequences + deliverability hygiene |
| CRM & RevOps | Truth model: held meetings, pipeline, source attribution |
| AI automation & agentic | Busywork on rails (routing, enrichment assists, summaries) — judgment stays human |

## What’s out

Net-new brand website programs, SEO retainers, and paid media as primary demand. Add Demand System when the same TAM needs site/SEO or ads.

Aligned with Clay/GTM median entry ($2k–$8k) and capacity-builder peers (e.g. GTM11-style transfer), not PE embed floors ($20k+/mo).

## Finish line

A client-owned stack that produces held meetings and pipeline dollars, with runbooks and training so an owner or hire can operate without a permanent embedded engineer.

## Transfer

Repo/docs for workflows, CRM health checks, sequence ownership, and a weekly business-review ritual. Dashboard path (D3) replaces “trust us” with numbers.
