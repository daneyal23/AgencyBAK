# Main Street packages

Three commercial SKUs that bundle the eight capability lines.
Grounded in `reports/Apero Advisors competitive landscape.md` (working price ladder) and
positioning in `docs/DECISIONS.md` (D1–D3, D5 draft).

**Rule:** published starting bands sit **below Apero’s Single-Channel floor (~$7.5k/mo)**.
Client owns domains, CRM, lists, and ad accounts. Build → operate → transfer.
Truth metric: **held** meetings (and pipeline dollars), not booked theatre.

| Package | One-liner | USD starting band | File |
|---------|-----------|-------------------|------|
| Pipeline Starter | Who to sell, how to say it, meetings that show | Build $3.5k–7k · Run $2.5k–4.5k/mo | [pipeline-starter.md](./pipeline-starter.md) |
| GTM Machine | The machine behind the pipeline — you can run it | Build $5k–12k · Run $4.5k–6.5k/mo | [gtm-machine.md](./gtm-machine.md) |
| Demand System | Same TAM across outbound, site/SEO or paid | Build $8k–15k · Run $5.5k–7k/mo | [demand-system.md](./demand-system.md) |

**Terms (all three):** 60–90 day pilot, then month-to-month. Optional hybrid: lower base + fee per **held** qualified meeting after pilot. Tooling (Clay credits, dialer, ad spend) pass-through. Multi-currency TBD (D7).

Drafted 2026-10-26. Bands are directional — confirm in sales before treating as hard public quotes.
